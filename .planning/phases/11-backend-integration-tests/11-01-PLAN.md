  <action>
Create `apps/backend/src/events/events.controller.spec.ts` with comprehensive controller integration tests. Follow the patterns from 11-RESEARCH.md exactly.

**Test app factory:** Create a `createTestApp(userOverride?)` helper function within the file that:
- Uses `Test.createTestingModule` with `controllers: [EventsController]` and `providers: [{ provide: EventsService, useValue: mockEventsService }]`
- Calls `.overrideGuard(SupabaseAuthGuard).useValue({ canActivate })` where canActivate injects `request.user = userOverride` (default: mockUser with `{ id: 'user-1', email: 'alice@example.com', role: 'authenticated', isSuperAdmin: false }`)
- Applies `ValidationPipe` with `whitelist: true, transform: true` and the EXACT `exceptionFactory` from `main.ts` (formats errors as `Record<string, string>` where key=property, value=first constraint message)
- Calls `app.init()` and returns the INestApplication

**Mock service:** Define `mockEventsService` at file scope with `jest.fn()` for ALL methods called by the controller: `createEvent`, `searchEvents`, `getPublicEvents`, `getEventsByOwner`, `getEventsCoOrganized`, `getEventById`, `updateEvent`, `publishEvent`, `deleteEvent`, `saveDraftEvent`, `updateOccurrence`, `updateFutureOccurrences`.

**Test suites to include:**

1. **GET /events/search (public):** Returns 200 with search results. Passes query params to service.searchEvents.

2. **GET /events/public (public):** Returns 200 with public events list.

3. **GET /events/:id (public):** Returns 200. Passes optional user context (user?.id, user?.isSuperAdmin) to getEventById.

4. **POST /events (authenticated):**
   - Valid payload returns 201, service receives (user.id, dto).
   - Missing `type` returns 400 with error on `type` property.
   - Invalid `type` (not jam/class/workshop/convention) returns 400.
   - Missing `starts_at` returns 400.
   - Unknown fields are stripped (whitelist: true) -- send `hacker_field`, verify service does NOT receive it.

5. **POST /events/draft (authenticated):** Valid draft payload returns 201. Passes user.id, dto, user.isSuperAdmin to service.

6. **GET /events/my-events (authenticated):** Returns 200, passes user.id to getEventsByOwner.

7. **GET /events/co-organized (authenticated):** Returns 200, passes user.id to getEventsCoOrganized.

8. **PATCH /events/:id (authenticated):**
   - Valid update returns 200. Service receives (id, user.id, dto, user.isSuperAdmin).
   - Service throws NotFoundException -> 404.
   - Service throws ForbiddenException -> 403.

9. **PATCH /events/:id/publish (authenticated):** Returns 200. Passes id, user.id, user.isSuperAdmin.

10. **DELETE /events/:id (authenticated):** Returns 200. Passes id, user.id, user.isSuperAdmin.

11. **Unauthorized access:** Create a separate describe block that builds the app with `canActivate: () => false`. Verify that `POST /events` returns 403.

**Import conventions:**
- `import request from 'supertest'` (default import, matching existing e2e test style)
- Import `NotFoundException`, `ForbiddenException` from `@nestjs/common` for error propagation tests
- Import `ExecutionContext` type from `@nestjs/common` for the canActivate mock

**beforeEach/afterEach:** Call `jest.clearAllMocks()` in beforeEach. Call `await app.close()` in afterEach to prevent hanging.
