**Key difference:** This controller uses nested routes: `@Controller('events/:eventId/organizers')`. All supertest requests must use paths like `/events/event-1/organizers`.

**Also note:** The `AddCoOrganizerDto` class is defined inline in the controller file (not in a separate dto/ file). It has a single `@IsString() userId` field. Import it from the controller file if needed for reference, but the test only needs to send the right/wrong body via supertest.

**Test suites:**

1. **GET /events/:eventId/organizers (authenticated):**
   - Returns 200 with co-organizers list. Service receives (eventId, user.id, user.isSuperAdmin).

2. **POST /events/:eventId/organizers (authenticated):**
   - Valid payload `{ userId: 'user-2' }` returns 201 (explicit @HttpCode). Service receives (eventId, user.id, 'user-2', user.isSuperAdmin).
   - Missing `userId` field returns 400.
   - Non-string `userId` (e.g., `{ userId: 123 }`) returns 400.

3. **DELETE /events/:eventId/organizers/:organizerId (authenticated):**
   - Returns 204 No Content (explicit @HttpCode). Service receives (eventId, organizerId, user.id, user.isSuperAdmin).
   - Service throws NotFoundException -> 404.
   - Service throws ForbiddenException -> 403.

4. **Error propagation:**
   - GET with service throwing ForbiddenException -> 403 (user not authorized to view organizers).
   - POST with service throwing NotFoundException -> 404 (event not found).
