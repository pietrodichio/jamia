## Decisions Made
- **IP auto-apply behavior:** IP location is auto-applied to URL on mount (not just staged) so users see search results immediately without clicking search button
- **Pending change indicator:** Uses ring-2 ring-primary/20 around location section plus a small primary-colored dot to indicate unsaved location selection
- **Mobile rendering:** Returns null for mobile screens - Plan 02 will add mobile modal pattern
- **Search trigger pattern:** Keyword changes update URL immediately (debounced), but location changes require explicit search button click
