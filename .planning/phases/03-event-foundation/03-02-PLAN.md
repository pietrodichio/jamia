**CreateEventDto (apps/backend/src/events/dto/create-event.dto.ts):**

Import decorators from class-validator and class-transformer.

```typescript
export class CreateEventDto {
  // Required: Event type
  @IsString()
  @IsIn(['jam', 'class', 'workshop', 'convention'])
  type: string;

  // Required: Core fields
  @IsString()
  title: string;

  @IsString()
  location_text: string;

  @IsDateString()
  starts_at: string;

  @IsDateString()
  ends_at: string;

  // Optional: Shared fields
  @IsOptional()
  @IsString()
  description?: string;

  @IsOptional()
  @IsString()
  price?: string;

  @IsOptional()
  @IsString()
  external_link?: string;

  @IsOptional()
  @IsString()
  organizer_contact?: string;

  // Optional: Location fields
  @IsOptional()
  @Type(() => Number)
  @IsNumber()
  location_lat?: number;

  @IsOptional()
  @Type(() => Number)
  @IsNumber()
  location_lng?: number;

  @IsOptional()
  @IsString()
  location_place_id?: string;

  @IsOptional()
  @IsString()
  gmaps_link?: string;
}
```

**UpdateEventDto (apps/backend/src/events/dto/update-event.dto.ts):**

Use PartialType from @nestjs/mapped-types to make all fields optional. Add status field for publishing.

```typescript
import { PartialType } from '@nestjs/mapped-types';
import { IsIn, IsOptional, IsString } from 'class-validator';
import { CreateEventDto } from './create-event.dto';

export class UpdateEventDto extends PartialType(CreateEventDto) {
  @IsOptional()
  @IsString()
  @IsIn(['draft', 'published', 'archived'])
  status?: string;
}
```

**Why this approach:** Single DTO with @IsIn for type validation. All event types share same core fields. Type-specific fields (like jam capacity) are NOT included here - those belong in the separate jams system. Events are "listings only" per requirements.

**Pitfall avoided:** Not using @ValidateIf for type-specific fields because events don't have type-specific required fields (per requirements, jams are managed separately, other events are simple listings).

<task type="auto">
  <name>Task 2: Create EventsService with CRUD and authorization</name>
  <files>apps/backend/src/events/events.service.ts</files>
  <action>
Create EventsService mirroring JamsService authorization pattern. Use existing SUPABASE_CLIENT injection.

**Key methods to implement:**

1. **isOwnerOrCoOrganizer(eventId, userId, isSuperAdmin)** - Authorization helper
   - Check isSuperAdmin FIRST (early return true)
   - Call Supabase RPC 'is_event_owner_or_organizer' with event_id and user_id
   - Return boolean result

2. **createEvent(ownerId, createEventDto)** - Create new event
   - Validate ends_at > starts_at (throw BadRequestException if not)
   - Insert into events table with owner_id = ownerId, status = 'draft'
   - Call auditService.log(eventId, ownerId, 'event_created', createEventDto)
   - Return created event

3. **getEventById(eventId, userId, isSuperAdmin)** - Get single event
   - Query events table with .eq('id', eventId).single()
   - Throw NotFoundException if not found
   - Return event

4. **getEventsByOwner(userId)** - Get user's owned events
   - Query events table with .eq('owner_id', userId)
   - Order by starts_at DESC
   - Return events array

5. **getEventsCoOrganized(userId)** - Get events user co-organizes
   - Join events with event_organizers
   - Filter event_organizers.user_id = userId
   - Return events array

6. **updateEvent(eventId, userId, updateEventDto, isSuperAdmin)** - Update event
   - Check authorization: isOwnerOrCoOrganizer(eventId, userId, isSuperAdmin)
   - Throw ForbiddenException if not authorized
   - If updating dates, validate ends_at > starts_at
   - Update in events table
   - Audit log with 'event_updated'
   - Return updated event

7. **deleteEvent(eventId, userId, isSuperAdmin)** - Delete event
   - Check owner ONLY (not co-organizers): query event, check owner_id = userId OR isSuperAdmin
   - Throw ForbiddenException if not owner/admin
   - Delete from events table (CASCADE handles event_organizers)
   - Audit log with 'event_deleted'
   - Return success

8. **publishEvent(eventId, userId, isSuperAdmin)** - Publish event
   - Check authorization with isOwnerOrCoOrganizer
   - Update status to 'published'
   - Audit log with 'event_published'
   - Return updated event

**Constructor injection:**
```typescript
constructor(
  @Inject(SUPABASE_CLIENT) private readonly supabase: SupabaseClient,
  private readonly auditService: AuditService,
) {}
```

**Why this pattern:** Proven in jams.service.ts. Service-level authorization before database operations. Audit logging for all mutations. Super admin check at service level (not just RLS).

**Critical pitfall:** ALWAYS throw ForbiddenException after failed authorization check. Don't let execution continue silently.

**EventsController (apps/backend/src/events/events.controller.ts):**

Use SupabaseAuthGuard on all routes. Extract user from @User() decorator.

Endpoints:
- POST /events - createEvent(@Body() createEventDto, @User() user)
  - Call eventsService.createEvent(user.id, createEventDto)
  - Return 201 Created

- GET /events/my-events - getMyEvents(@User() user)
  - Call eventsService.getEventsByOwner(user.id)
  - Return owned events

- GET /events/co-organized - getCoOrganizedEvents(@User() user)
  - Call eventsService.getEventsCoOrganized(user.id)
  - Return co-organized events

- GET /events/:id - getEvent(@Param('id') id, @User() user)
  - Call eventsService.getEventById(id, user.id, user.isSuperAdmin)
  - Return event

- PATCH /events/:id - updateEvent(@Param('id') id, @Body() updateEventDto, @User() user)
  - Call eventsService.updateEvent(id, user.id, updateEventDto, user.isSuperAdmin)
  - Return updated event

- PATCH /events/:id/publish - publishEvent(@Param('id') id, @User() user)
  - Call eventsService.publishEvent(id, user.id, user.isSuperAdmin)
  - Return published event

- DELETE /events/:id - deleteEvent(@Param('id') id, @User() user)
  - Call eventsService.deleteEvent(id, user.id, user.isSuperAdmin)
  - Return 204 No Content
