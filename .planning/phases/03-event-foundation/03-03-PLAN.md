<task type="auto">
  <name>Task 1: Create EventOrganizersService mirroring ManagersService</name>
  <files>apps/backend/src/event-organizers/event-organizers.service.ts</files>
  <action>
Create EventOrganizersService as exact mirror of ManagersService but for events. Copy proven validation patterns.

**Key methods to implement:**

1. **addCoOrganizer(eventId, ownerId, coOrganizerUserId, isSuperAdmin)** - Add co-organizer
   - Query event from events table with .eq('id', eventId).single()
   - Throw NotFoundException if event doesn't exist
   - Check authorization: event.owner_id === ownerId OR isSuperAdmin
   - Throw ForbiddenException if not owner/admin: "Only the event owner can add co-organizers"
   - Validate ownerId !== coOrganizerUserId
   - Throw BadRequestException if same: "The owner cannot be added as a co-organizer"
   - Query profiles table to verify user exists: .eq('id', coOrganizerUserId).single()
   - Throw NotFoundException if user doesn't exist: "User not found"
   - Check if already co-organizer: query event_organizers with event_id + user_id
   - Throw BadRequestException if already exists: "User is already a co-organizer for this event"
   - Insert into event_organizers: { event_id, user_id: coOrganizerUserId, added_by: ownerId }
   - Audit log with 'organizer_added', metadata: { co_organizer_user_id: coOrganizerUserId }
   - Return inserted record

2. **getCoOrganizers(eventId, userId, isSuperAdmin)** - Get event's co-organizers
   - Query event to verify access (owner, co-organizer, or admin)
   - Throw ForbiddenException if no access
   - Query event_organizers joined with profiles
   - Select: organizer id, user_id, profiles(id, name, email, photo_url)
   - Return array of co-organizers with user details

3. **removeCoOrganizer(eventId, organizerId, userId, isSuperAdmin)** - Remove co-organizer
   - Query event to verify ownership: event.owner_id === userId OR isSuperAdmin
   - Throw ForbiddenException if not owner/admin: "Only the event owner can remove co-organizers"
   - Delete from event_organizers where id = organizerId AND event_id = eventId
   - Throw NotFoundException if no rows affected
   - Audit log with 'organizer_removed', metadata: { organizer_id: organizerId }
   - Return success

**Constructor injection:**
```typescript
constructor(
  @Inject(SUPABASE_CLIENT) private readonly supabase: SupabaseClient,
  private readonly auditService: AuditService,
) {}
```

**Why this pattern:** Exact mirror of managers.service.ts which is production-tested. All validations from research pitfalls section. Owner-only permissions for add/remove (co-organizers can edit events but not manage co-organizers).

**Critical validations (from research pitfalls):**
- Owner !== co-organizer (prevent owner adding themselves)
- User exists (prevent dangling references)
- Not already co-organizer (prevent duplicates)
- Super admin check FIRST in all authorization
