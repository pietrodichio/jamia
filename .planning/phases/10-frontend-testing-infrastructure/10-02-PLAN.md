**File 1: `apps/web/src/hooks/useEventFilters.test.ts`**

This hook reads/writes URL search params via `useSearchParams` from react-router-dom. It needs a MemoryRouter wrapper.

Test cases:
1. `returns default filter values from empty URL` - No params, verify defaults (query='', radius='50', types=[], etc.)
2. `reads existing URL params` - Use initialEntries with `/?query=yoga&radius=100`, verify filters reflect those values
3. `updateFilter sets a string param` - Call updateFilter('query', 'acro'), verify filters.query changes
4. `updateFilter sets array params (types)` - Call updateFilter('type', ['jam', 'workshop']), verify filters.types
5. `updateFilter removes param when value is empty string` - Call updateFilter('query', ''), verify param removed
6. `clearFilters removes all params` - Set some params, call clearFilters, verify all defaults
7. `setTags updates tag params` - Call setTags(['beginner-friendly', 'mat-required']), verify tags

**Wrapper for this hook:** Use MemoryRouter directly (no QueryClient needed since this hook doesn't use React Query):
```typescript
import { renderHook, act } from '@testing-library/react';
import { MemoryRouter } from 'react-router-dom';

function createWrapper(initialEntries: string[] = ['/']) {
  return function Wrapper({ children }: { children: React.ReactNode }) {
    return <MemoryRouter initialEntries={initialEntries}>{children}</MemoryRouter>;
  };
}
```

CRITICAL: Do NOT destructure `result.current` - always access `result.current.filters.query` etc. after `act()`.

**Wrapper for this hook:** Needs QueryClientProvider with retry:false:
```typescript
import { renderHook, waitFor } from '@testing-library/react';
import { QueryClientProvider } from '@tanstack/react-query';
import { createTestQueryClient } from '@/test/render-utils';

function createWrapper() {
  const queryClient = createTestQueryClient();
  return function Wrapper({ children }: { children: React.ReactNode }) {
    return <QueryClientProvider client={queryClient}>{children}</QueryClientProvider>;
  };
}
```

Import `server` from `@/test/msw-server` and `http`, `HttpResponse` from `msw` for the error test override.

CRITICAL: Do NOT destructure `result.current` - access `result.current.data`, `result.current.isSuccess`, `result.current.isError` directly after `waitFor`.

**File 3: `apps/web/src/hooks/useDebounce.test.ts`**

This hook uses setTimeout internally. Use `vi.useFakeTimers()` to control time.

Test cases:
1. `returns initial value immediately` - Render with value='hello' and delay=500, verify returns 'hello' immediately
2. `does not update before delay` - Rerender with value='world', advance timer by 200ms, verify still returns 'hello'
3. `updates after delay` - Rerender with value='world', advance timer by 500ms, verify returns 'world'
4. `resets timer on rapid changes` - Rerender with 'a', then immediately with 'b', advance by 500ms, verify returns 'b' (not 'a')

**Pattern for fake timers:**
```typescript
beforeEach(() => {
  vi.useFakeTimers();
});

afterEach(() => {
  vi.useRealTimers();
});
```

Use `act(() => { vi.advanceTimersByTime(500); })` to advance the timer. The hook uses `useState` internally so state updates must be wrapped in `act`.

Use `renderHook` with `initialProps` and `rerender`:
```typescript
const { result, rerender } = renderHook(
  ({ value, delay }) => useDebounce(value, delay),
  { initialProps: { value: 'hello', delay: 500 } }
);

expect(result.current).toBe('hello');

rerender({ value: 'world', delay: 500 });
// value hasn't changed yet
expect(result.current).toBe('hello');

act(() => { vi.advanceTimersByTime(500); });
expect(result.current).toBe('world');
```
