  <action>
Create two new hooks:

**useIpLocation.ts:**
- Use React Query with queryKey ['ip-location']
- Fetch from https://ipapi.co/json/
- Return { lat, lng, city, isApproximate: true }
- Configure: staleTime: 5 * 60 * 1000 (5 min), gcTime: 30 * 60 * 1000 (30 min), retry: 1
- Handle both latitude/longitude and lat/lon response formats (ipapi uses both)
- Export type IpLocationResult with lat, lng, city, isApproximate fields

**useGeolocationPermission.ts:**
- Check navigator.permissions.query({ name: 'geolocation' }) on mount
- Handle Safari not supporting Permissions API (catch and return 'unsupported')
- Track state changes via result.onchange
- Return permission state: 'granted' | 'denied' | 'prompt' | 'unsupported'
- This enables smart UI adaptation without triggering permission prompts
  </action>
