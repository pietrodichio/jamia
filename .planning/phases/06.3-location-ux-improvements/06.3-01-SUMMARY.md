## Decisions Made
- **ipapi.co as IP geolocation provider** - Free tier, JSON API, handles both lat/lon and latitude/longitude response formats
- **5 minute staleTime, 30 minute gcTime** - Balances freshness with rate limiting concerns
- **useRef for hasAutoApplied** - Prevents re-triggering auto-apply after user clears location manually
- **enableHighAccuracy: true for GPS only** - GPS requests are user-initiated, worth the extra battery for precision
