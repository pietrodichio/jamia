  <name>Task 1: Preserve git history using merge strategy</name>
  <files>
    .git/**
    apps/backend/**
    apps/web/**
  </files>
  <action>
Follow Pattern 6 from research (Git History Preservation) with git merge --allow-unrelated-histories:

Step 1: Add frontend as remote and fetch
```bash
git remote add frontend-temp ./jamia-fe
git fetch frontend-temp
```

Step 2: Merge frontend preserving history
```bash
git merge frontend-temp/main --allow-unrelated-histories --no-commit
```

Step 3: Move all files to apps/web
```bash
mkdir -p apps/web
# Move all files (careful with hidden files)
shopt -s dotglob
mv jamia-fe/* apps/web/ 2>/dev/null || true
# Move hidden files explicitly if needed
mv jamia-fe/.* apps/web/ 2>/dev/null || true
rmdir jamia-fe 2>/dev/null || true
```

Step 4: Stage and commit frontend merge
```bash
git add apps/web
git commit -m "feat(monorepo): merge jamia-fe into apps/web

Preserves full git history from frontend repository.
All commits, authors, and timestamps retained.

Co-Authored-By: Claude Sonnet 4.5 <noreply@anthropic.com>"
```

Step 5: Clean up remote
```bash
git remote remove frontend-temp
```

Step 6: Add backend as remote and fetch
```bash
git remote add backend-temp ./jamia-be
git fetch backend-temp
```

Step 7: Merge backend preserving history
```bash
git merge backend-temp/main --allow-unrelated-histories --no-commit
```

Step 8: Move all files to apps/backend
```bash
mkdir -p apps/backend
# Move all files
shopt -s dotglob
mv jamia-be/* apps/backend/ 2>/dev/null || true
mv jamia-be/.* apps/backend/ 2>/dev/null || true
rmdir jamia-be 2>/dev/null || true
```

Step 9: Stage and commit backend merge
```bash
git add apps/backend
git commit -m "feat(monorepo): merge jamia-be into apps/backend

Preserves full git history from backend repository.
All commits, authors, and timestamps retained.

Co-Authored-By: Claude Sonnet 4.5 <noreply@anthropic.com>"
```

Step 10: Clean up remote
```bash
git remote remove backend-temp
```

Why this approach: Research identifies git merge --allow-unrelated-histories as simpler than git subtree for 2-repo migration. Preserves full history, attribution, and bisect capability. Creates clean directory structure in apps/.

Why separate commits: Each merge gets its own commit for clear history. Makes it easy to track when each repo was integrated.

IMPORTANT: This task operates on the existing git repository root (/Users/pietrodichio/development/personal/jamia/). The jamia-fe and jamia-be directories already exist as subdirectories. This merges their histories into the current repository.
