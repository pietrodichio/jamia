  <action>
Create root package.json following research pattern:
- Set "private": true (not published)
- Add "packageManager": "pnpm@10.22.0"
- Add "engines": {"node": ">=22"}
- Add scripts: "build": "turbo run build", "dev": "turbo run dev", "test": "turbo run test", "lint": "turbo run lint"
- Add devDependency: "turbo": "latest"
- Keep workspace references minimal (no dependencies)

Create pnpm-workspace.yaml:
```yaml
packages:
  - 'apps/*'
  - 'packages/*'
```

Create turbo.json following research example:
- Schema: "https://turbo.build/schema.json"
- Define tasks: build, dev, test, lint
- build: dependsOn ["^build"], outputs ["dist/**", ".next/**", "!.next/cache/**", "build/**"]
- dev: dependsOn ["^build"], cache: false, persistent: true
- test: dependsOn ["^build"]
- lint: cache: false
- Add globalEnv: ["NODE_ENV"]

Create tsconfig.base.json for shared TypeScript settings:
- target: "ES2023"
- module: "ESNext"
- moduleResolution: "bundler"
- strict: true
- esModuleInterop: true
- skipLibCheck: true
- forceConsistentCasingInFileNames: true

Update .gitignore to add:
- .turbo
- dist
- build
- node_modules
- .env*.local

Why these files: Research (01-RESEARCH.md) identifies these as core monorepo foundation. Turborepo requires turbo.json for task orchestration. pnpm-workspace.yaml defines workspace boundaries. Base tsconfig provides shared compiler settings.
  </action>
  <verify>
Run: pnpm install
Run: turbo run build --dry-run=json
Check: Output shows workspace structure discovered
Check: No errors about missing configurations
  </verify>
  <done>
- Root package.json exists with turbo devDependency
- pnpm-workspace.yaml defines apps/* and packages/*
- turbo.json has valid pipeline with build/dev/test tasks
- tsconfig.base.json provides shared TS config
- pnpm install completes without errors
  </done>
