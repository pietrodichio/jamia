  <action>
    1. Create `apps/backend/src/digest/dto/curated-events.dto.ts`:
       - Define `DigestEvent` interface with fields: id, type, title, starts_at, ends_at, location_city, image_url, created_at (matching events table columns needed for email cards)
       - Define `GroupedEvents` interface: { conventions: DigestEvent[], workshops: DigestEvent[], jams: DigestEvent[] }
       - Define `CuratedEvents` interface: { upcoming: GroupedEvents, new: GroupedEvents }
       - Define `SubscribedUser` interface: { user_id: string, email: string, first_name: string | null, unsubscribe_token: string, last_digest_sent_at: string | null, digest_frequency: string }

    2. Create `apps/backend/src/digest/digest.service.ts`:
       - Injectable service with Logger, inject SUPABASE_CLIENT
       - Method `getSubscribedUsers(frequency: 'weekly' | 'monthly'): Promise<SubscribedUser[]>`:
         - Query email_preferences table joined with profiles table
         - Filter: digest_enabled = true AND digest_frequency = frequency
         - Select: user_id, profiles.email, profiles.first_name, unsubscribe_token, last_digest_sent_at, digest_frequency
         - Use service role client (bypasses RLS) since this is a server-side scheduled job
         - The Supabase client injected via SUPABASE_CLIENT already uses service role key
       - Method `curateEventsForUser(lastDigestSentAt: string | null): Promise<CuratedEvents>`:
         - Query 1 - Upcoming events:
           - from('events'), select id, type, title, starts_at, ends_at, location_city, image_url
           - Filter: status = 'published', type IN ('convention', 'workshop', 'jam'), starts_at >= now
           - Order by starts_at ascending
           - Limit 9 (will be grouped to max 3 per type)
         - Query 2 - New events (only if lastDigestSentAt is not null):
           - Same select and type/status filters
           - Filter: created_at >= lastDigestSentAt
           - Order by created_at descending
           - Limit 9
           - If lastDigestSentAt is null, return empty arrays for new section
         - Dedup: collect upcoming event IDs into a Set, filter new events to exclude any ID in the Set
         - Group both result sets using groupByType helper
       - Private method `groupByType(events: DigestEvent[], maxPerType: number): GroupedEvents`:
         - Filter events by type, slice to maxPerType
         - Return { conventions, workshops, jams } in priority order
       - Method `hasEvents(curated: CuratedEvents): boolean`:
         - Returns true if any group in either section has at least one event
         - Used to skip empty digests
       - Method `updateLastDigestSentAt(userId: string): Promise<void>`:
         - Update email_preferences SET last_digest_sent_at = NOW() WHERE user_id = userId

    3. Create `apps/backend/src/digest/digest.module.ts`:
       - Import ScheduleModule.forRoot() -- this initializes the cron scheduler globally
       - Import EmailPreferencesModule (for potential future use, but mainly we query directly)
       - Import EmailModule (will be needed by Plan 03 for sending)
       - Providers: [DigestService]
       - Exports: [DigestService]

    4. Register DigestModule in `apps/backend/src/app.module.ts`:
       - Add import statement for DigestModule
       - Add DigestModule to the imports array

    5. Verify the app starts:
       ```bash
       cd apps/backend && pnpm run build
       ```
