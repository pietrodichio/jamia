## Decisions Made

1. **Client-side compression before upload** - Using browser-image-compression to compress images to max 1MB and 1920px before uploading reduces storage costs and bandwidth usage
2. **File type validation** - Limited to JPEG, PNG, and WebP formats for broad compatibility and efficient compression
3. **5MB maximum file size** - Prevents users from uploading excessively large files while allowing high-quality photos
4. **Optional image upload** - Image is optional in wizard, can be skipped or added later for flexibility
5. **Preview-before-upload** - Shows preview card with uploaded image and remove button for better UX
6. **Hidden file input pattern** - Uses useRef to trigger hidden file input from styled Button for better visual design
