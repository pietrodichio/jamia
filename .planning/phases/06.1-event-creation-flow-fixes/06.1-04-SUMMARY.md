## Decisions Made

**Auto-fill end time defaults (+4 hours):** When user selects start date/time, end time auto-fills to 4 hours later. This is a sensible default for most events:
- **Rationale:** 4 hours covers typical event durations (2-4 hour jams, 2-3 hour classes, multi-hour workshops)
- **User control:** Only auto-fills when end_date/end_time not already set (non-destructive)
- **Safety:** Capped at 23:59 same day to prevent crossing day boundary unexpectedly

**500ms debounce on auto-fill:** Auto-fill logic debounced to prevent excessive form updates while user types/selects:
- **Rationale:** Prevents recalculating end time on every keystroke in time input
- **User experience:** Smoother interaction, no jarring immediate updates
- **Performance:** Reduces unnecessary form setValue() calls

**Conditional RecurrenceEditor for class type:** RecurrenceEditor only shown when eventType === 'class':
- **Rationale:** Recurring events primarily used for weekly classes, not one-time jams/workshops/conventions
- **Future extension:** Can add to other types if needed (convention multi-day tracks, weekly workshops)
- **Form cleanup:** shouldUnregister: true ensures recurrence fields removed when switching away from class type

**Non-destructive auto-fill:** shouldDirty: false prevents marking form dirty:
- **Rationale:** Auto-filled values are suggestions, not user input
- **User experience:** Prevents "unsaved changes" warning when user hasn't actually changed anything
