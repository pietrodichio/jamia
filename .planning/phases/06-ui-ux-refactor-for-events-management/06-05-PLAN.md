<task type="auto">
  <name>Task 2: Implement draft auto-save hook</name>
  <files>
    apps/web/src/hooks/useAutoSave.ts
  </files>
  <action>
    Create useAutoSave hook at apps/web/src/hooks/useAutoSave.ts:
    - Import useDebounce from use-debounce (already in project)
    - Import useState, useEffect from react
    - Import supabase from @/integrations/supabase/client

    Hook signature:
    ```typescript
    function useAutoSave(formData: Partial<EventFormData>, eventId?: string): {
      saveStatus: 'idle' | 'saving' | 'saved' | 'error';
      draftId: string | undefined;
    }
    ```

    Implementation:
    1. Debounce formData with 1000ms delay (use useDebounce)
    2. Track saveStatus state: idle, saving, saved, error
    3. Track draftId state (for subsequent saves)

    Auto-save logic in useEffect:
    - Skip if formData.title is empty (don't save blank forms)
    - Set saveStatus to 'saving'
    - Upsert to events table:
      ```typescript
      const { data, error } = await supabase
        .from('events')
        .upsert({
          id: eventId || draftId, // Use existing ID if available
          ...debouncedFormData,
          status: 'draft',
          updated_at: new Date().toISOString(),
        }, {
          onConflict: 'id',
          ignoreDuplicates: false,
        })
        .select()
        .single();
      ```
    - On success: set saveStatus to 'saved', store data.id as draftId
    - On error: set saveStatus to 'error', log error
    - Return draftId for subsequent saves

    Error handling:
    - Catch Supabase errors (network, auth, validation)
    - Log to console but don't block UI
    - Show subtle indicator in UI (handled by CreateEvent page)

    Reference RESEARCH.md Pattern 3 for implementation details and Pitfall 3 for upsert pattern.
  </action>
  <verify>
    - Check useAutoSave.ts exists in apps/web/src/hooks/
    - Check hook uses useDebounce with 1000ms delay
    - Check upsert includes onConflict: 'id' to update existing drafts
    - Check hook returns saveStatus and draftId
    - Run `pnpm --filter @jamia/web build` to verify hook compiles
  </verify>
  <done>

    - Hook upserts to events table with status='draft'
    - Existing drafts updated by ID (no duplicate records)

  </done>
