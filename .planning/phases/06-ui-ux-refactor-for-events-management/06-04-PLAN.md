    - Back button: hidden on step 1, variant="outline", Italian "Indietro"
    - Next button: shown on steps 1-2, Italian "Avanti", disabled if !canGoNext
    - Submit button: shown on step 3, Italian "Pubblica", disabled if isSubmitting
    - Layout: flex justify-between with gap-4

    Create useEventWizard hook at apps/web/src/hooks/useEventWizard.ts:
    - Manages wizard state: current step (1-3)
    - Uses React Hook Form with shouldUnregister: true (critical for conditional fields)
    - Provides nextStep() function: validates current step fields, increments if valid
    - Provides prevStep() function: decrements step (no validation needed for backward)
    - Provides getStepFields() function: returns field names for current step
    - Returns: { currentStep, nextStep, prevStep, form, isStepValid }

    Step field mapping:
    - Step 1: ['type', 'title', 'description', 'location']
    - Step 2: ['date', 'time', 'end_date', 'end_time', 'price', 'link']
    - Step 3: [] (no validation, just preview)

    Validation logic in nextStep():
    ```typescript
    const nextStep = async () => {
      const fields = getStepFields(currentStep);
      const isValid = await form.trigger(fields);
      if (isValid) setCurrentStep(prev => prev + 1);
    };
    ```

    Reference RESEARCH.md Pattern 2 and "React Hook Form Wizard Step Validation" code example.
